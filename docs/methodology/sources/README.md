# 📚 Regulatory sources

Copies of the texts K-SFTs's methodology relies on, so that a citation
and its formula can be checked against the exact version that was read. The
[source register](../README.md#source-register) says what each text is used
for and how far it was read. Selected texts only: a registered source is
copied when a rule or a scope decision relies on it or will be read for one,
and only the parts needed; registered future versions are not copied.

These are documentation copies, not the authentic texts. The authentic EU
texts are those published in the Official Journal of the European Union; the
Basel Framework's authoritative text is the one on bis.org; EBA Q&As are
published on eba.europa.eu.

**Do not edit or reformat these files**, and never replace one: their hashes
are registered below, and a changed byte breaks the record. A newer version
is added as a new file next to the old one, with its own row.
`.gitattributes` keeps them out of line-ending normalization.

On 2026-10-24 the first copies of the CRR and CRE22, an XHTML extract and an
HTML page with its formula images, were replaced by the PDFs below, which
hold the same versions, by maintainer decision: a PDF can be cited by page
and shows each formula in place. They are in the Git history.

## ✂️ How the copies were made

- **CRR extract.** The full consolidated text was retrieved as PDF/A-2a from
  the Publications Office: 895 pages, SHA-256
  `6796302ed4213bcba4d4b9b17dc48aefcaf7ef586b875c30c8c71a7689288ecf`, the
  same file as the EUR-Lex PDF of this version (EUR-Lex itself could not be
  reached from the environment used). Page 1 and pages 281 to 323 were cut
  from it with pypdf 6.2.1, which copies pages without changing their
  content and keeps shared fonts shared. Checked: the text of every page
  (`pdftotext -layout`) equals the same page of the full file; rendered at
  50 dpi, the pages differ only in anti-aliasing (at most 16 of 255 grey
  levels), and the formulas of Article 220(3) are present.
  The same file was retrieved as XHTML first (SHA-256
  `2d041b5b32d4020fa1decb3bb64e835d6fcb747c5274a61f785b195a9dc9e6ad`).
- **Basel chapters (CRE22, CRE32, CRE50, CRE51, CRE53, CRE54, CRE56).** Each
  chapter PDF as served, unchanged. bis.org does not serve one version
  reliably: the same address returned the version in force on one download
  and a future (2028) or earlier version on another, with or without the
  `version` parameter. Each file was therefore accepted only when its first
  page read the version in force recorded in the
  [source register](../README.md#source-register) (*Version effective as of
  …*), and downloaded again otherwise. bis.org generates the PDF on each
  download, with the download time as its creation date, so a new download
  does not give the registered hash; the version line is what identifies it.
- **Cross-check of the six chapters added later.** The text of CRE32, CRE50,
  CRE51, CRE53, CRE54 and CRE56 equals, apart from the cover page and page
  footers, the same chapters in an independent extract from the full Basel
  Framework PDF that the maintainer prepared on 2026-10-24 (commit
  `380df17` on a branch deleted unmerged the same day; the extract is not
  in the repository).
- **EBA Q&As.** Text copied from each page's HTML; only the layout and white
  space differ: list items are one line each, and the submitter's name and
  country are omitted. The HTML pages are not committed.

To check the files against the hashes above, from the repository root:

```sh
python -c "import glob,hashlib;[print(hashlib.sha256(open(f,'rb').read()).hexdigest(),f) for f in sorted(glob.glob('docs/methodology/sources/*')) if not f.endswith('README.md')]"
```
