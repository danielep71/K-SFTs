01 / The calculation

Transactions. Haircuts. Netting.

The prototype covers repos and reverse repos, securities lending and borrowing, and margin lending. Its financial collateral comprehensive method makes the exposure and collateral adjustments visible.

  1. 01 / INPUT

    Describe both sides

    Record cash and securities given or received, link the legs to transactions, and assign transactions to their netting sets.

  2. 02 / ADJUST

    Apply supervisory haircuts

    Use the collateral classification, holding period and applicable currency adjustment. Inspect the parameters and the assumptions behind them.

  3. 03 / AGGREGATE

    Follow the exposure

    Calculate E* under an eligible master netting agreement, or calculate each transaction separately and sum the results.

Prototype outputsE*Exposure valueRWRisk weightRWARisk-weighted exposure8% × RWAOwn funds requirement

The EU CRR controls the intended methodology, with the Basel Framework as reference. The prototype currently offers both CRR and BCBS regimes; that departure remains documented. The outputs above describe the prototype, not a complete bank capital framework.

02 / The wider framework

One exposure engine in a larger picture.

K-SFTs provides the securities financing exposure component. The prototype also calculates standardised risk-weighted exposure and own funds per netting set, including a QCCP trade-exposure class. Default-fund capital and CVA are not implemented here.

03 / Get started

Build from source. Inspect in Excel.

1. Clone the active development branch

A Git clone preserves the checkout conventions expected by the VBA editor.

git clone --branch release/0.3.0 https://github.com/danielep71/K-SFTs.git
cd K-SFTs

2. Assemble a development workbook

Start from the macro-free template and import the exported VBA using the documented setup. Compile and run the checks in desktop Excel for Windows.

The repository does not distribute a released macro-enabled workbook.
